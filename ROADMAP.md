## Milestone sequence for each project

1. Requirements and acceptance criteria.
2. Architecture, data/API design where relevant, and threat model.
3. A runnable core implementation.
4. Automated tests and static checks appropriate to the language.
5. Reproducible build and CI; deployment assets when relevant.
6. Usage, architecture, limitations, and release notes.

Mark a stage complete only when its deliverable exists and has been reviewed.
See [PROJECT-STATUS.md](PROJECT-STATUS.md) for the active queue and evidence.
